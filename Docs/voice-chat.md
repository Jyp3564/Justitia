# 인게임 음성 대화

Steam에 로그인하고 세션에 입장한 뒤 V 키를 누르는 동안 발언한다. 상대가 연결되어 있으면 음성을 전송한다.
Esc → 음성 설정에서 마이크를 켜고 끄거나 상대 음성 볼륨을 0~100%로 조절한다.
설정은 다음 실행에도 유지된다. 화면 상단에 마이크 상태가 표시된다.
입력 장치는 Steam의 음성 설정에서 선택한다. Windows에서 데스크톱 앱 마이크 접근을 허용해야 한다.
상대가 없거나 세션에서 나가면 캡처를 멈춘다. 메뉴를 열면 발언을 중단한다. 한국어 STT 테스트 사용법은 stt-korean.md를 참고한다.
헤드셋 사용을 권장한다. 게임에서 자체 에코 제거는 하지 않는다.

Steam Voice 압축 → NGO의 900바이트 분할 비신뢰 전송 → 상대 Steam Voice 복호화 → Unity 스트리밍 AudioSource.
Steam/LAN 모두 Steam 로그인된 클라이언트에서 사용 가능하다. Steam 미로그인 LAN은 음성을 지원하지 않는다.
현재 승인된 상대의 패킷만 처리하며, 누락되거나 300ms 이상 지난 조각은 폐기한다.
재생 대기는 최대 500ms로 제한하고, STT 변환 중 임시 WAV 파일을 사용하고 작업 종료 시 제거한다. 인식 결과는 테스트 로그에 출력한다.

검증: Unity 컴파일, 연결 전 캡처 비활성, 음소거/볼륨 제어, 역순 패킷 재조립, 잘못된 코덱 데이터 무음 처리.
두 PC의 실제 마이크 송수신 및 청취 품질은 실사용 검증이 필요하다.
공식 API: https://partner.steamgames.com/doc/features/voice
