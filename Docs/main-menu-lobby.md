# 메인 메뉴 및 대기 로비

게임 시작 → 방 만들기 / 방 참가 / 설정 / 종료.
방 만들기는 Steam 방을 생성하고 곧바로 대기 로비를 연다. 아직 캐릭터 시점으로 입장하지 않는다.
로비에서 Host가 정의의 법정 맵을 선택한다. 현재 제공되는 맵은 기존 법정 하나이며 이후 맵 추가가 가능하다.
선택한 맵과 준비 상태는 Host 스냅샷으로 Guest에게 동기화한다. Guest는 맵을 변경할 수 없다.
맵 선택 + 양쪽 준비 완료 → Host 주제/라운드 제출 → 양쪽 캐릭터 시점으로 게임 입장.

방 참가 → Steam 친구가 연 호환 방 목록 새로고침 → 참가. Steam 초대 수락도 지원한다.
LAN 탭에서는 IP 참가와 테스트용 방 생성이 가능하다. LAN을 선택하고 메인 메뉴로 돌아오면 방 만들기도 LAN을 사용한다.
메인 설정은 마이크 음소거 및 상대 음성 볼륨을 제공한다. 로비에서도 친구 초대와 음성 설정을 사용할 수 있다.
V 키 발언·한국어 STT는 대기 로비에서 테스트할 수 있다. 주제 입력 중, 설정/친구 목록을 연 동안에는 발언을 막는다.

통신 프로토콜 v2: 양쪽 모두 새 빌드를 사용해야 한다. 맵 미선택 또는 알려지지 않은 맵을 가진 시작 스냅샷은 거부한다.
메인 메뉴와 카드의 크기는 화면에 맞춰 축소하여 좁은 화면에서도 모든 항목을 표시한다.
